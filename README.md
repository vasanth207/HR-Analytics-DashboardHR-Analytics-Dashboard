# HR Analytics Dashboard using Power BI

## Overview

This project is an interactive HR Analytics Dashboard built using Microsoft Power BI.

It helps HR teams analyze employee information, workforce performance, training outcomes, and business units through interactive visualizations.

---

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- CSV Dataset

---

## Features

- Total Employees KPI
- Active Employees KPI
- Average Age
- Average Rating
- Average Satisfaction
- Average Engagement

Interactive Filters

- Department
- Gender
- Business Unit
- State
- Employee Type

Charts

- Employees by Department
- Employees by Gender
- Employees by Business Unit
- Employees by State
- Employee Type
- Performance Score
- Training Outcome
